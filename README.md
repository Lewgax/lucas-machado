# Portfólio de Lucas Machado

Site estático em HTML e CSS, publicado no GitHub Pages.

Site: https://lewgax.github.io/lucas-machado/

Publicação: em Settings → Pages, selecionar Deploy from a branch, branch main e pasta / (root).

As imagens são ilustrativas, geradas por IA. A apresentação está em index.html; os projetos estão em ensaios-de-brocas.html, montagem-colaborativa.html e universal-robots.html. Os estilos estão em style.css. Todos os arquivos ficam na raiz do repositório.
